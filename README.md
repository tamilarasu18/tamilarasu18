## 🚀 Featured Projects

### 🎓 CodeForge — Multi-Tenant Campus Coding-Assessment Platform

Full-stack SaaS for college coding assessments, architected and shipped solo in ~2 weeks via AI-assisted development.
**~56K LOC · 20 backend modules · 109 REST endpoints · 28-table Postgres schema**

- ⚙️ **Judging pipeline:** queue → worker pool → sandboxed compile/run → verdict → live WebSocket push, across 5 languages and 6 verdict types
- 🔌 **Ports & adapters:** pluggable local / Piston execution engines behind one port interface, with a Redis cache for deterministic verdicts only
- 🏛️ **Multi-tenancy:** repository-level tenant scoping, per-host subdomain resolution, per-college branding from a single brand colour, seat-licence enforcement
- 🛡️ **Proctoring:** fullscreen capture, tab-blur & paste detection, typing forensics, risk scoring, WebRTC screen-share invigilation wall
- 🔁 **CI/CD:** GitHub Actions → idempotent migrations against real Postgres → snapshot-backed SSH deploy to Azure (Caddy / Redis / Piston Docker stack)
- 📦 Cut the React bundle from **~290 KB → ~57 KB gzipped** via lazy routes and vendor splitting

### 🎬 Story-to-Video AI Pipeline

A fully autonomous multi-model generative pipeline that turns a prompt into a published video — no human in the loop after trigger.

| Stage | Technology |
| ----- | ---------- |
| 📝 Story generation | Gemma 3 |
| 🎙️ Voice synthesis | Kokoro TTS |
| 📜 Timed subtitles | OpenAI Whisper |
| 🎨 Scene visuals | Stable Diffusion |
| 📹 Composition | MoviePy |
| ☁️ Publishing | YouTube Data API via GCS |

Each model is exposed as a REST service on **FastAPI** and orchestrated into one scheduled workflow that auto-publishes to a live channel.
